# PaperTrail — seekdb 技术验证与复现报告

## 1. 验证目的

本报告用于证明 PaperTrail 的核心数据管理与检索功能真实依赖 seekdb，而不是使用前端模拟数据或其他数据库替代。

验证内容覆盖数据写入、查询、关键词检索、阅读状态过滤、更新、删除、统计以及跨进程持久化。

## 2. 技术与运行环境

- Python：3.11+
- pyseekdb：1.4.0.post1
- pylibseekdb：1.4.0.post2
- FastAPI：0.162.2
- uvicorn：0.54.0
- 数据库：seekdb 嵌入式模式
- 验证脚本：`scripts/verify_seekdb.py`
- 验证数据库目录：`data/verify_seekdb.db`

项目通过 pyseekdb SDK 访问真实 seekdb 数据库。

## 7. seekdb 在项目中的具体作用

### 数据存储

通过 Collection API 持久化文献记录，包括标题、作者、摘要、标签、阅读状态和个人笔记等字段。

### 文献查询

通过 `get` 接口按 ID 获取文献，通过元数据条件过滤阅读状态。

### 关键词检索

将文献文本内容写入 seekdb document 字段，使用 `where_document` 实现全文匹配与正则子串匹配。

针对中文复合词和停用字可能导致的检索偏差，项目采用全文检索与子串匹配结合的策略。

### 数据修改与删除

通过 `update`、`delete` 修改数据库记录，并在后续查询中验证变更效果。

### 持久化

通过两个独立 Python 进程依次打开相同的数据目录，验证文献及修改结果在进程结束后仍然存在。

## 8. 运行应用进行人工复现

安装依赖：

```bash
cd qoder
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

启动应用：

```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器访问：

`http://127.0.0.1:8000`

评审可通过以下操作进一步核验：

1. 打开文献库，查看演示文献。
2. 搜索 `Transformer`，确认能够检索出相关文献。
3. 新增一篇文献，并通过关键词搜索找到。
4. 修改该文献的阅读状态与笔记。
5. 刷新页面，确认修改仍存在。
6. 删除该文献，确认列表中不再显示。

核心 API 可通过 FastAPI 自动生成的 `/docs` 页面查看。

## 9. 已知运行限制

开发和截图过程中曾观察到嵌入式 seekdb 长时间运行后出现 `Server has gone away (code=2006)` 连接异常。

当时重启应用后恢复了数据库访问，原有数据仍然保留。

该问题尚未证明已经从代码层面永久解决。因此，评审运行时如遇连接异常，可先停止并重新启动应用；若问题持续发生，应保留日志并排查。

## 10. 验证结论

根据实际测试执行记录：

- 功能验证：27 项通过，0 项失败。

验证结果表明，seekdb 实际承担了 PaperTrail 的核心文献数据存储、查询、检索及持久化功能。
